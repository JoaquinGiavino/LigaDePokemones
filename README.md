# Pokémon League - Gestión de Entrenadores

Aplicación web desarrollada con JavaScript puro que permite gestionar entrenadores Pokémon, integrando datos en tiempo real desde la PokeAPI. Incluye visualización de entrenadores, registro de nuevos perfiles y selección de equipos Pokémon con paginación.

## Características
- 🎮 Gestión completa de entrenadores Pokémon
- 📡 Consumo de PokeAPI para obtener datos reales de Pokémon
- 💾 Persistencia de datos (localStorage + simulación JSON)
- 🎨 Diseño moderno con CSS Glassmorphism
- 📱 Totalmente responsive

## Tecnologías
- HTML5, CSS3, JavaScript ES6
- PokeAPI (REST)
- LocalStorage para persistencia
